# Catálogo v2 de calculadoras - calculadoras.tools

Estado base del proyecto: 29 calculadoras publicadas en 13 categorías. Este catálogo amplía el inventario original y separa las ideas por esfuerzo técnico.

## Leyenda

- `[DONE]`: calculadora ya publicada.
- `[SIN BACKEND]`: se puede resolver con fórmulas, datos ingresados por el usuario o tablas estáticas.
- `[DATOS LOCALES]`: requiere tablas locales, presets o revisión editorial periódica, pero no una API en vivo.
- `[BACKEND/API]`: requiere tasas, datos externos, geocoding, precios, cotizaciones o actualización automática.
- `[ALTO CUIDADO]`: tema sensible; necesita disclaimers claros, fuentes y límites de uso.

## Notas de priorización

- Las calculadoras `[SIN BACKEND]` deben alimentar el roadmap inmediato.
