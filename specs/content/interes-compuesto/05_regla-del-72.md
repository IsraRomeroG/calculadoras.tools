## Promesa del articulo

Ensenar un atajo mental para estimar el tiempo de duplicacion con una tasa anual fija, y explicar sus limites para no confundir estimacion con garantia.

## Formula principal

```txt
anos para duplicar = 72 / tasa anual
```

Ejemplo:

```txt
72 / 8 = 9 anos aproximadamente
```
