- Tasas de CETES cambian con el mercado.

## Estructura recomendada

1. `## CETES e interes compuesto: la idea basica`
   - Comprar CETES por un plazo no es automaticamente una tasa fija de muchos anos.
   - El compuesto depende de reinvertir al vencimiento.
2. `## Como se calcula una ganancia simple de CETES`
   - Monto, plazo, tasa.
   - Formula de referencia de Cetesdirecto: interes bruto proporcional al plazo.
3. `## Donde entra la reinversion`
   - Reinvertir capital + rendimiento.
   - Cada nuevo periodo puede tener otra tasa.
4. `## Ejemplo educativo`
   - Usar tasa hipotetica claramente marcada.
   - Comparar retirar intereses vs reinvertirlos.
5. `## Que datos debes revisar antes de calcular`
   - Tasa vigente.
   - Plazo.
   - ISR.
   - Liquidez.
   - Si la reinversion esta activa.
6. `## Usa la calculadora como aproximacion`
   - Si quieres simular una tasa anual constante, usar calculadora.
   - Aclarar que CETES reales pueden cambiar de tasa cada vencimiento.
