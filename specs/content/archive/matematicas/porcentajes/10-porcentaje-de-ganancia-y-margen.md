## Mensaje central

El margen usa el precio de venta como base; el markup usa el costo como base. Por eso no son intercambiables aunque ambos hablen de ganancia.

## Estructura recomendada

1. Introduccion: problema comun de confundir margen con markup.
2. `## Que es el porcentaje de ganancia`
   - Ganancia = precio de venta - costo.
3. `## Como calcular el margen de ganancia`
   - Formula: `ganancia / precio de venta * 100`.
4. `## Como calcular el markup`
   - Formula: `ganancia / costo * 100`.
5. `## Ejemplo con costo de 100 y venta de 150`
   - Ganancia: 50.
   - Margen: 33.33%.
   - Markup: 50%.
6. `## Margen vs markup: tabla comparativa`
   - Base de calculo, uso comun, formula.
7. `## Errores comunes al fijar precios`
   - Aplicar margen como si fuera markup.
   - No incluir comisiones, envio o impuestos.
