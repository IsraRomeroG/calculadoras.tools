Convertir correctamente la tasa es esencial para calcular intereses. Si tienes una tasa anual y la usas como si fuera mensual, el resultado queda completamente distorsionado.

En préstamos, la periodicidad importa: no es lo mismo una tasa anual, mensual, quincenal o diaria. Esta guía usa conversiones simples para estimaciones; una institución puede aplicar metodologías específicas.

## Por qué importa la periodicidad de la tasa

La tasa debe coincidir con el periodo del cálculo. Si vas a calcular intereses de un mes, necesitas una tasa mensual. Si vas a calcular intereses diarios, necesitas una tasa diaria.

La [calculadora de préstamo](/finanzas/calculadora-de-prestamo) pide tasa de interés anual. Internamente la convierte a una tasa mensual para estimar la cuota y la tabla de amortización.

## Cómo convertir tasa anual a mensual

Para una estimación simple:

```txt
tasa mensual simple = tasa anual / 12
```

Ejemplo:

```txt
24% anual / 12 = 2% mensual
```

En decimal:

```txt
2% = 0.02
```

Esa tasa mensual se puede usar para estimar el interés del mes sobre el saldo pendiente.

## Cómo estimar una tasa diaria

Para una estimación diaria simple, divide la tasa anual entre 360 o 365:

```txt
tasa diaria simple = tasa anual / 360
tasa diaria simple = tasa anual / 365
```

Con una tasa anual de `24%`:

```txt
24% / 360 = 0.0667% diario aproximado
24% / 365 = 0.0658% diario aproximado
```

No afirmes que una base sea universal. El uso de 360 o 365 días depende de metodología, contrato, producto y país.

## Ejemplo con tasa anual de 24%

Supongamos un saldo pendiente de `$50,000` y tasa anual de `24%`.

Primero conviertes a tasa mensual:

```txt
24% / 12 = 2%
```

Luego calculas el interés del mes:

```txt
interés del mes = 50000 x 0.02
interés del mes = 1000
```

El interés estimado del mes sería `$1,000`.

Si quisieras estimar un día con base 360:

```txt
24% / 360 = 0.0667%
50000 x 0.000667 = 33.33
```

El interés diario aproximado sería `$33.33`, antes de considerar metodología exacta, impuestos o redondeos.

## Error común: escribir tasa mensual como anual

Si tu crédito muestra una tasa mensual de `2%` y la escribes como tasa anual `2%` en una calculadora que espera tasa anual, estarás subestimando el costo.

También puede ocurrir lo contrario: escribir `24%` como si fuera tasa mensual en una fórmula mensual. Ese error puede hacer que la mensualidad parezca imposible.

Antes de calcular, confirma:

- La tasa está expresada anual, mensual o diaria?
- Es nominal o efectiva?
- Incluye comisiones o solo intereses?
- La calculadora pide tasa anual o mensual?

## Qué tasa usar en la calculadora

En la [calculadora de préstamo](/finanzas/calculadora-de-prestamo), usa la tasa anual. Si tienes una tasa mensual, puedes anualizarla de forma simple multiplicando por 12 para una estimación inicial, pero revisa si se trata de tasa efectiva o nominal.

Para entender el efecto en la cuota, revisa también [cómo calcular la cuota mensual de un préstamo](/blog/como-calcular-cuota-mensual-prestamo), [cómo calcular intereses](/blog/como-calcular-intereses-prestamo) y [CAT vs tasa de interés](/blog/cat-vs-tasa-interes).

## Preguntas frecuentes

### Puedo dividir la tasa anual entre 12?

Sí, para una estimación mensual simple. Si necesitas un cálculo formal, revisa la metodología del crédito.

### Qué pasa si mi tasa es mensual?

No la escribas directamente en un campo que pide tasa anual. Convierte o confirma con la institución cómo debe interpretarse.

### La tasa diaria usa 360 o 365 días?

Depende del contrato y metodología. Para estimaciones puedes mostrar ambas bases, pero no asumir que una aplica siempre.

### La tasa de la calculadora debe ser anual?

Sí. La calculadora de préstamo pide tasa de interés anual y la convierte internamente para el cálculo mensual.
