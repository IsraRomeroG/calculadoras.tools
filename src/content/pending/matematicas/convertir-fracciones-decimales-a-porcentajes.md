Un porcentaje es una forma de expresar una proporción sobre 100. Por eso, `0.25`, `1/4` y `25%` representan la misma cantidad: veinticinco de cada cien.

La idea principal es sencilla: para convertir un decimal a porcentaje multiplicas por 100; para convertir un porcentaje a decimal divides entre 100. Si tienes una fracción, primero la conviertes a decimal y luego a porcentaje.

## Cómo convertir un decimal a porcentaje

Para pasar de decimal a porcentaje, multiplica el decimal por 100 y agrega el signo `%`.

```txt
porcentaje = decimal x 100
```

Por ejemplo:

```txt
0.25 x 100 = 25%
```

Entonces:

```txt
0.25 = 25%
```

Otro ejemplo común:

```txt
0.5 x 100 = 50%
```

Así que `0.5 = 50%`, no `0.5%`.

## Cómo convertir un porcentaje a decimal

Para pasar de porcentaje a decimal, divide entre 100 y quita el signo `%`.

```txt
decimal = porcentaje / 100
```

Por ejemplo:

```txt
25 / 100 = 0.25
```

Entonces:

```txt
25% = 0.25
```

Este paso es útil cuando vas a usar un porcentaje dentro de una fórmula. Por ejemplo, para calcular 20% de una cantidad puedes usar `0.20` como multiplicador.

## Cómo convertir una fracción a porcentaje

Para convertir una fracción a porcentaje, divide el numerador entre el denominador y después multiplica el resultado por 100.

```txt
porcentaje = numerador / denominador x 100
```

Con `1/4`:

```txt
1 / 4 = 0.25
0.25 x 100 = 25%
```

Entonces:

```txt
1/4 = 25%
```

Con `3/4`:

```txt
3 / 4 = 0.75
0.75 x 100 = 75%
```

Entonces:

```txt
3/4 = 75%
```

También puedes resolverlo con [regla de tres](/blog/regla-de-tres): si el denominador representa el 100%, el numerador representa el porcentaje que buscas.

## Errores comunes

El error más común es olvidar multiplicar por 100. Si haces `1 / 4 = 0.25`, todavía tienes un decimal. Para escribirlo como porcentaje falta hacer:

```txt
0.25 x 100 = 25%
```

Otro error frecuente es confundir `0.5` con `0.5%`. No son lo mismo:

```txt
0.5 = 50%
0.5% = 0.005
```

La diferencia es grande porque `0.5` significa medio entero, mientras que `0.5%` significa medio de cada cien.

También conviene cuidar el orden cuando conviertes de porcentaje a decimal. `8%` se escribe como `0.08`, no como `0.8`. El decimal `0.8` equivale a `80%`.

## Cómo usarlo en cálculos de porcentaje

Estas conversiones sirven como base para casi todos los cálculos porcentuales. Si quieres calcular 25% de 200, puedes convertir `25%` a `0.25` y multiplicar:

```txt
200 x 0.25 = 50
```

Si quieres saber qué porcentaje representa una cantidad respecto a otra, la operación se parece mucho: divides la parte entre el total y multiplicas por 100. Puedes verlo con más detalle en [qué porcentaje es una cantidad de otra](/blog/que-porcentaje-es-una-cantidad-de-otra).

## Preguntas frecuentes

**¿Cómo convertir 0.25 a porcentaje?**

Multiplica por 100: `0.25 x 100 = 25%`. Por eso `0.25 = 25%`.

**¿Cuánto es 1/4 en porcentaje?**

`1/4` es `25%`. Primero divides `1 / 4 = 0.25` y después multiplicas por 100: `0.25 x 100 = 25%`.

**¿Cómo pasar de porcentaje a decimal?**

Divide el porcentaje entre 100 y quita el signo `%`. Por ejemplo, `75% / 100 = 0.75`.

**¿Por qué 0.5 no es 0.5%?**

Porque `0.5` es un decimal que equivale a `50%`. En cambio, `0.5%` es un porcentaje muy pequeño: al dividirlo entre 100 queda `0.005`.
