Restar un porcentaje a una cantidad significa quitar una parte proporcional del valor original. Es lo que haces cuando calculas un descuento, una rebaja, una retención o una reducción sobre una base.

Por ejemplo, si quieres calcular `1,000 - 20%`, no restas 20 unidades. Primero calculas el 20% de 1,000 y después lo descuentas. El resultado final es 800.

## Fórmula para restar un porcentaje

Hay dos formas equivalentes de hacer el cálculo. La primera calcula el descuento por separado:

```txt
descuento = base x porcentaje / 100
final = base - descuento
```

La segunda usa un multiplicador directo:

```txt
final = base x (1 - porcentaje / 100)
```

Ambas fórmulas llegan al mismo resultado. La primera es útil cuando quieres saber cuánto se quitó. La segunda es más rápida cuando solo necesitas el valor final.

## Ejemplo paso a paso

Supón que tienes una cantidad de $1,000 y quieres restarle 20%.

Primero calcula el porcentaje que se va a descontar:

```txt
1,000 x 20 / 100 = 200
```

Después resta ese descuento a la cantidad original:

```txt
1,000 - 200 = 800
```

Entonces:

```txt
1,000 - 20% = 800
```

Con el método directo, sería:

```txt
1,000 x (1 - 20 / 100) = 1,000 x 0.80 = 800
```

## Tabla de descuentos comunes

Cuando restas un porcentaje, puedes convertirlo en un multiplicador. Para restar 10%, multiplicas por `0.90`; para restar 20%, multiplicas por `0.80`; para restar 50%, multiplicas por `0.50`.

| Porcentaje a restar | Multiplicador |  Ejemplo con 1,000 |
| ------------------: | ------------: | -----------------: |
|                  5% |          0.95 | 1,000 x 0.95 = 950 |
|                 10% |          0.90 | 1,000 x 0.90 = 900 |
|                 15% |          0.85 | 1,000 x 0.85 = 850 |
|                 20% |          0.80 | 1,000 x 0.80 = 800 |
|                 25% |          0.75 | 1,000 x 0.75 = 750 |
|                 50% |          0.50 | 1,000 x 0.50 = 500 |

La lógica siempre es la misma: el multiplicador representa la parte que queda después de quitar el porcentaje. Si restas 25%, queda el 75% de la cantidad original.

## Ejemplos comunes

Estos ejemplos muestran el resultado final después de quitar el porcentaje:

| Operación   | Cálculo directo | Resultado |
| ----------- | --------------: | --------: |
| 1,000 - 20% |    1,000 x 0.80 |       800 |
| 750 - 15%   |      750 x 0.85 |    637.50 |
| 500 - 8%    |      500 x 0.92 |       460 |
| 2,400 - 25% |    2,400 x 0.75 |     1,800 |

Si el caso es una compra, también puedes ver la guía específica de [cómo calcular un descuento](/blog/porcentaje-de-descuento).

## Cuándo se usa

En rebajas de tiendas, restar un porcentaje permite obtener el precio final. Si una chamarra cuesta $750 y tiene 15% de descuento, el precio final es `750 x 0.85 = 637.50`.

En retenciones, el porcentaje representa una parte que se descuenta de un pago o importe bruto. La operación matemática es la misma, aunque el significado contable o fiscal dependa del caso.

En presupuestos, sirve para estimar reducciones. Si un presupuesto de $2,400 baja 25%, el nuevo monto es $1,800.

También aplica fuera del dinero. Puedes restar un porcentaje a cantidades de piezas, metas, tiempo, peso o cualquier valor que tenga una base clara.

Cuando hay más de una rebaja, no conviene sumar porcentajes sin revisar la base. En ese caso el tema relacionado son los [descuentos sucesivos](/blog/descuentos-sucesivos), porque cada descuento se calcula sobre el valor que queda después del anterior.

## Diferencia entre restar porcentaje y calcular disminución porcentual

Restar un porcentaje parte de una base conocida y produce un valor final. Por ejemplo, si sabes que una cantidad de 500 baja 8%, calculas:

```txt
500 x 0.92 = 460
```

La disminución porcentual responde otra pregunta: compara un valor inicial con un valor final ya conocidos para saber qué porcentaje bajó. Por ejemplo, si algo pasó de 500 a 460, la disminución fue de 8%.

En resumen: restar porcentaje sirve para calcular el resultado después de quitar una parte. La [disminución porcentual](/blog/disminucion-porcentual) sirve para medir cuánto bajó algo entre dos valores.

## Calcúlalo con la calculadora

Si quieres obtener el resultado sin hacer la operación a mano, usa la [calculadora de porcentajes](/matematicas/calculadora-de-porcentajes) y elige el modo "Restar %".

Ese modo está pensado para escribir una cantidad base y el porcentaje que quieres quitar. La calculadora muestra el descuento y el resultado final, así puedes revisar tanto la parte restada como la cantidad que queda.

## Preguntas frecuentes

**¿Cómo quitar el 20% a una cantidad?**

Multiplica la cantidad por `0.80`. Por ejemplo, `1,000 x 0.80 = 800`. También puedes calcular primero el 20%, que en este caso es 200, y restarlo a la cantidad original.

**¿Por qué no es lo mismo restar 20 que restar 20%?**

Porque 20 es una cantidad fija y 20% depende de la base. El 20% de 1,000 es 200, pero el 20% de 500 es 100.

**¿Cómo calcular el precio final con descuento?**

Multiplica el precio original por `1 - descuento / 100`. Si el precio es $750 y el descuento es 15%, el precio final es `750 x 0.85 = 637.50`.

**¿Puede quedar un resultado negativo al restar un porcentaje?**

Sí, si restas más del 100%. Por ejemplo, quitar 120% a una cantidad deja un valor negativo. En descuentos comerciales normales, lo habitual es que el porcentaje esté entre 0% y 100%.
