Sumar un porcentaje a una cantidad significa aumentar un número base en cierta proporción. Es lo que haces cuando agregas IVA, una comisión, una propina, un recargo o un incremento de precio.

Por ejemplo, si quieres calcular `500 + 16%`, no sumas 16 unidades. Primero calculas el 16% de 500 y después lo agregas al valor original. El resultado es 580.

## Fórmula para sumar un porcentaje

Hay dos formas equivalentes de hacer el cálculo. La primera separa el incremento del total:

```txt
incremento = base x porcentaje / 100
total = base + incremento
```

La segunda usa un multiplicador directo:

```txt
total = base x (1 + porcentaje / 100)
```

Ambas llegan al mismo resultado. La primera es útil cuando quieres ver cuánto aumenta la cantidad. La segunda es más rápida cuando solo necesitas el total final.

## Ejemplo paso a paso

Supón que tienes un precio de $500 y quieres sumarle 16%.

Primero calcula el incremento:

```txt
500 x 16 / 100 = 80
```

Después suma ese incremento al precio original:

```txt
500 + 80 = 580
```

Entonces:

```txt
500 + 16% = 580
```

Con el método directo, sería:

```txt
500 x (1 + 16 / 100) = 500 x 1.16 = 580
```

## Atajo con multiplicadores

Cuando sumas un porcentaje, puedes convertirlo en un multiplicador. Para sumar 10%, multiplicas por `1.10`; para sumar 16%, multiplicas por `1.16`; para sumar 25%, multiplicas por `1.25`.

| Porcentaje a sumar | Multiplicador | Ejemplo |
|---:|---:|---:|
| 8% | 1.08 | 300 x 1.08 = 324 |
| 10% | 1.10 | 1,200 x 1.10 = 1,320 |
| 16% | 1.16 | 500 x 1.16 = 580 |
| 20% | 1.20 | 750 x 1.20 = 900 |
| 25% | 1.25 | 850 x 1.25 = 1,062.50 |

La lógica siempre es la misma: el `1` representa el 100% de la cantidad original y la parte decimal representa el porcentaje adicional.

## Ejemplos comunes

Estos ejemplos muestran el total después de sumar el porcentaje:

| Operación | Cálculo directo | Resultado |
|---|---:|---:|
| 500 + 16% | 500 x 1.16 | 580 |
| 1,200 + 10% | 1,200 x 1.10 | 1,320 |
| 850 + 25% | 850 x 1.25 | 1,062.50 |
| 300 + 8% | 300 x 1.08 | 324 |

Si quieres repasar la base antes de usar atajos, puedes leer la guía de [cómo calcular porcentajes](/blog/como-calcular-porcentajes).

## Casos de uso frecuentes

En precios con recargo, el porcentaje adicional puede representar una comisión, una tarifa por servicio o un ajuste por pago tardío. Si un producto cuesta $1,200 y tiene un recargo de 10%, el total será $1,320.

En salarios, sumar un porcentaje ayuda a estimar el nuevo sueldo después de un aumento. Si un salario pasa de $20,000 con un aumento de 8%, el nuevo monto sería `20,000 x 1.08 = 21,600`.

En propinas, puedes sumar 10%, 15% o 20% al consumo para obtener el total aproximado a pagar. Por ejemplo, una cuenta de $850 con 25% adicional queda en $1,062.50.

En impuestos como el IVA, el procedimiento matemático es el mismo: se calcula el impuesto sobre la base y se agrega al precio. Para ese caso específico, también puedes ver la guía de [cómo sumar IVA a un precio](/blog/como-sumar-iva-a-un-precio).

Cuando comparas un valor inicial con un valor final y quieres saber qué tanto creció, el tema relacionado es el [aumento porcentual](/blog/aumento-porcentual).

## Errores comunes

Un error frecuente es sumar el número del porcentaje como si fuera una cantidad fija. Por ejemplo, `500 + 16%` no es `500 + 16`; es `500 + 80`, porque 80 es el 16% de 500.

Otro error es confundir sumar un porcentaje con calcular qué porcentaje representa una cantidad de otra. No es lo mismo aumentar 500 en 16% que preguntar qué porcentaje es 80 de 500.

También conviene evitar redondear demasiado pronto. Si haces varios cálculos, guarda decimales hasta el final y redondea solo el resultado que vas a mostrar.

## Calcúlalo con la calculadora

Si quieres obtener el resultado sin hacer la operación a mano, usa la [calculadora de porcentajes](/matematicas/calculadora-de-porcentajes) y elige el modo "Sumar %".

Ese modo está pensado para escribir una cantidad base y el porcentaje que quieres agregar. La calculadora muestra el incremento y el total final, así puedes revisar tanto la parte añadida como el resultado.

## Preguntas frecuentes

**¿Cómo sumar 10% a una cantidad?**

Multiplica la cantidad por `1.10`. Por ejemplo, `1,200 x 1.10 = 1,320`. También puedes calcular el 10% por separado y sumarlo al valor original.

**¿Cómo sumar 16% a un precio?**

Multiplica el precio por `1.16`. Por ejemplo, `500 x 1.16 = 580`. Si quieres ver el desglose, el 16% de 500 es 80 y el total es 580.

**¿Es mejor multiplicar por 1.16 o sumar el incremento?**

Depende de lo que necesites. Multiplicar por `1.16` es más rápido para obtener el total. Calcular primero el incremento es mejor si quieres explicar cuánto se agregó.

**¿Qué diferencia hay entre sumar porcentaje y aumento porcentual?**

Sumar un porcentaje sirve para obtener el valor final después de agregarlo a una base. El aumento porcentual sirve para comparar dos valores ya conocidos y medir cuánto creció uno respecto al otro.
