Para saber qué porcentaje es una cantidad de otra, divide la parte entre el total y multiplica por 100.

```txt
parte / total x 100
```

Por ejemplo, si quieres saber qué porcentaje es 45 de 200:

```txt
45 / 200 x 100 = 22.5%
```

Eso significa que 45 representa el 22.5% de 200.

## Fórmula para saber qué porcentaje es una cantidad de otra

La fórmula es:

```txt
porcentaje = parte / total x 100
```

La clave es identificar bien cada dato:

- La parte es la cantidad que quieres comparar.
- El total es la cantidad completa o base.

En la pregunta "qué porcentaje es X de Y", normalmente X es la parte y Y es el total. Si inviertes el orden, el resultado cambia.

## Ejemplo rápido: cuánto porcentaje es 45 de 200

Primero identifica los datos:

```txt
parte = 45
total = 200
```

Después aplica la fórmula:

```txt
45 / 200 x 100 = 22.5%
```

En palabras: 45 es el 22.5% de 200.

## Ejemplos comunes

| Pregunta | Cálculo | Resultado |
|---|---:|---:|
| ¿Qué porcentaje es 18 de 60? | 18 / 60 x 100 | 30% |
| ¿Qué porcentaje es 75 de 300? | 75 / 300 x 100 | 25% |
| ¿Qué porcentaje es 120 de 500? | 120 / 500 x 100 | 24% |
| ¿Qué porcentaje es 7 de 10? | 7 / 10 x 100 | 70% |
| ¿Qué porcentaje es 250 de 1,000? | 250 / 1,000 x 100 | 25% |

## Cómo usarlo en compras, calificaciones y metas

En compras, este cálculo sirve para saber cuánto representa un gasto respecto a tu presupuesto. Si gastaste $250 de un presupuesto de $1,000, usaste el 25%.

En calificaciones, la parte puede ser el número de aciertos y el total puede ser el número de preguntas. Si respondiste bien 7 de 10 preguntas, obtuviste 70%.

En metas, la parte puede ser tu avance actual y el total puede ser el objetivo. Si llevas 120 de 500 unidades, tu avance es de 24%.

También puedes plantearlo como una proporción con [regla de tres](/blog/matematicas/regla-de-tres): si el total equivale a 100%, la parte equivale al porcentaje que buscas.

## Errores comunes

El error más común es invertir parte y total. No es lo mismo calcular 45 de 200 que 200 de 45. En el primer caso el resultado es 22.5%; en el segundo, el resultado sería mayor a 100%.

Otro error es usar un total igual a cero. No se puede dividir entre cero, así que el porcentaje no está definido si no existe una base de comparación.

También conviene no confundir porcentaje con puntos porcentuales. Un porcentaje compara una parte con un total; los puntos porcentuales comparan diferencias entre porcentajes ya calculados.

Para ver esa diferencia con ejemplos de tasas y encuestas, revisa [porcentaje vs puntos porcentuales](/blog/matematicas/porcentaje-vs-puntos-porcentuales).

## Preguntas frecuentes

**¿Qué pasa si el total es cero?**

No se puede calcular el porcentaje porque la fórmula divide entre el total. Dividir entre cero no tiene un resultado válido.

**¿Cómo se calcula qué porcentaje representa una cantidad?**

Divide la cantidad que representa la parte entre el total y multiplica por 100. La fórmula es `parte / total x 100`.

**¿Es lo mismo dividir entre el total que usar regla de tres?**

Sí, para este caso llegan al mismo resultado. Dividir entre el total y multiplicar por 100 es la forma directa de resolver la proporción.

**¿Qué significa si el resultado es mayor a 100%?**

Significa que la parte es mayor que el total. Por ejemplo, 120 de 100 equivale a 120%.
