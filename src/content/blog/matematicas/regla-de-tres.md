## Para qué sirve

La regla de tres sirve para encontrar un valor desconocido cuando tienes dos cantidades relacionadas proporcionalmente.

Por ejemplo: si 3 productos cuestan $180, ¿cuánto cuestan 5 productos?

También puede ayudarte a entender porcentajes, porque muchos cálculos se reducen a una proporción. Para esa base, revisa [cómo calcular porcentajes](/blog/matematicas/como-calcular-porcentajes/).

## Plantea la proporción

Primero acomoda los datos que sí conoces:

```txt
3 productos -> $180
5 productos -> x
```

Después multiplica en cruz y divide entre el dato restante:

```txt
x = 5 x 180 / 3
x = 300
```

Los 5 productos cuestan $300.

## Identifica si la relación es directa

La regla de tres directa aplica cuando ambas cantidades suben o bajan juntas. Si compras más productos, pagas más. Si recorres más distancia a la misma velocidad, tardas más tiempo.

Cuando una cantidad sube y la otra baja, como más personas haciendo el mismo trabajo en menos tiempo, se trata de una regla de tres inversa.

## Revisa las unidades

Antes de calcular, asegúrate de usar unidades compatibles. Si mezclas horas con minutos o pesos con centavos, convierte todo a la misma unidad para evitar resultados confusos.
