## La fórmula básica

Un porcentaje representa una parte de cada 100. Por eso, para calcular el porcentaje de una cantidad solo necesitas convertir el porcentaje a decimal y multiplicarlo por el número base.

Por ejemplo, para calcular el 20% de 350:

```txt
350 x 20 / 100 = 70
```

También puedes pensarlo como:

```txt
350 x 0.20 = 70
```

## Cuando quieres saber qué porcentaje representa una cantidad

Si quieres saber qué porcentaje es una cantidad respecto a otra, divide la parte entre el total y multiplica por 100.

```txt
45 / 200 x 100 = 22.5%
```

Esto significa que 45 representa el 22.5% de 200.

Esta operación también se puede plantear con [regla de tres](/blog/matematicas/regla-de-tres), porque estás comparando una parte contra un total equivalente a 100%.

## Aumentos y disminuciones

Para calcular una variación porcentual entre dos valores, resta el valor original al valor nuevo, divide entre el valor original y multiplica por 100.

```txt
(valor nuevo - valor original) / valor original x 100
```

Si pasas de 80 a 100:

```txt
(100 - 80) / 80 x 100 = 25%
```

El resultado indica un aumento del 25%.

Si quieres ver ese caso con más detalle, revisa la guía de [aumento porcentual](/blog/matematicas/aumento-porcentual). Para compras y rebajas, también puedes consultar [cómo calcular un descuento](/blog/finanzas/porcentaje-de-descuento).

## Errores comunes

Un error frecuente es sumar puntos porcentuales como si fueran porcentajes relativos. Subir de 20% a 30% no es un aumento del 10%, sino de 10 puntos porcentuales. El aumento relativo es del 50% porque 10 es la mitad de 20.

También conviene revisar la base del cálculo. El 15% de 1,000 no es lo mismo que el 15% de 850, aunque el porcentaje sea el mismo.

## Cuándo usar una calculadora

Si solo necesitas una estimación rápida, la fórmula mental puede ser suficiente. Si comparas precios, impuestos, aumentos salariales o variaciones entre periodos, una calculadora evita errores pequeños que pueden cambiar la decisión final.
