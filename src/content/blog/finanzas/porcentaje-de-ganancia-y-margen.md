El porcentaje de ganancia ayuda a entender cuánto ganas al vender un producto o servicio. El problema es que en negocios se usan palabras parecidas para cálculos distintos: ganancia, margen y markup.

La diferencia importante está en la base. El margen de ganancia usa el precio de venta como base. El markup usa el costo como base. Por eso no son intercambiables, aunque ambos describan la utilidad.

Si compras algo en $100 y lo vendes en $150, la ganancia es $50. Esa ganancia equivale a 33.33% de margen sobre el precio de venta, pero a 50% de markup sobre el costo.

## Qué es el porcentaje de ganancia

La ganancia es la diferencia entre el precio de venta y el costo.

```txt
ganancia = precio de venta - costo
```

Si un producto cuesta $200 y lo vendes en $260:

```txt
260 - 200 = 60
```

La ganancia es $60. Ese dato en dinero es el punto de partida, pero para compararlo con otros productos conviene convertirlo a porcentaje.

Ahí aparecen dos formas comunes de medirlo:

- Margen: compara la ganancia contra el precio de venta.
- Markup: compara la ganancia contra el costo.

Ambas pueden ser útiles. Lo importante es no mezclarlas al fijar precios, reportar resultados o comparar productos.

## Cómo calcular el margen de ganancia

El margen de ganancia indica qué parte del precio de venta queda como ganancia.

```txt
margen = ganancia / precio de venta x 100
```

Si vendes en $150 algo que costó $100, la ganancia es $50. Entonces:

```txt
50 / 150 x 100 = 33.33%
```

El margen de ganancia es 33.33%. En otras palabras, de cada $150 vendidos, $50 son ganancia antes de considerar otros gastos, comisiones, impuestos o costos indirectos.

El margen suele usarse para analizar rentabilidad porque se calcula sobre lo que realmente entra por la venta.

## Cómo calcular el markup

El markup indica cuánto se aumentó el costo para llegar al precio de venta.

```txt
markup = ganancia / costo x 100
```

Con el mismo ejemplo, si el costo fue $100 y la ganancia fue $50:

```txt
50 / 100 x 100 = 50%
```

El markup es 50%. Eso significa que al costo de $100 se le agregó 50% para obtener un precio de venta de $150.

El markup suele usarse al construir precios desde el costo. Por ejemplo, si quieres vender algo que cuesta $80 con un markup de 25%, agregas $20 y el precio queda en $100.

## Ejemplo con costo de 100 y venta de 150

Este ejemplo muestra por qué margen y markup no dan el mismo resultado.

```txt
costo = 100
precio de venta = 150
ganancia = 150 - 100 = 50
```

Ahora calcula el margen:

```txt
50 / 150 x 100 = 33.33%
```

Y calcula el markup:

```txt
50 / 100 x 100 = 50%
```

La ganancia en dinero es la misma: $50. Lo que cambia es la base del porcentaje. El margen pregunta "qué porcentaje del precio de venta es ganancia". El markup pregunta "qué porcentaje se agregó sobre el costo".

| Markup | Costo | ganancia / costo x 100 | Definir precio desde el costo |
| Ganancia | Diferencia en dinero | venta - costo | Saber cuánto queda antes de otros gastos |

También se puede ver con números:

| Costo | Precio de venta | Ganancia | Margen | Markup |
|---:|---:|---:|---:|---:|

Observa que el markup siempre queda más alto que el margen cuando hay ganancia positiva, porque divide la misma ganancia entre una base menor: el costo.

## Errores comunes al fijar precios

Un error frecuente es aplicar margen como si fuera markup. Por ejemplo, si quieres un margen de 30% y solo sumas 30% al costo, no obtienes 30% de margen.

Con un costo de $100, sumar 30% deja un precio de $130:

```txt
ganancia = 130 - 100 = 30
margen = 30 / 130 x 100 = 23.08%
```

El markup fue 30%, pero el margen real fue 23.08%. Para lograr un margen específico necesitas calcular el precio con otra fórmula:

```txt
precio de venta = costo / (1 - margen / 100)
```

Si el costo es $100 y quieres 30% de margen:

```txt
100 / (1 - 30 / 100) = 142.86
```

Vendiendo en $142.86, la ganancia es $42.86 y eso sí representa 30% del precio de venta.

Otro error es olvidar costos adicionales. Comisiones de plataforma, pasarela de pago, envío, empaques, devoluciones, descuentos, impuestos y gastos operativos pueden cambiar la utilidad real. ## Preguntas frecuentes

**¿Margen y markup son lo mismo?**

No. El margen usa el precio de venta como base. El markup usa el costo como base. Con costo de $100 y venta de $150, el margen es 33.33%, pero el markup es 50%.

**¿Cómo calcular el porcentaje de ganancia?**

Primero calcula la ganancia con `precio de venta - costo`. Después decide la base: para margen divide la ganancia entre el precio de venta; para markup divide la ganancia entre el costo.

**¿Qué base se usa para el margen de ganancia?**

El margen usa el precio de venta como base. La fórmula es `ganancia / precio de venta x 100`.

**¿Cómo saber a qué precio vender para lograr cierto margen?**

Usa `precio de venta = costo / (1 - margen / 100)`. Por ejemplo, con costo de $100 y margen deseado de 30%, el precio de venta sería $142.86.

**¿Los impuestos se incluyen en el margen?**

Depende de cómo lleves tus precios y reportes. Para estimar utilidad real conviene separar impuestos, comisiones y costos adicionales, porque pueden reducir el margen disponible para el negocio.
