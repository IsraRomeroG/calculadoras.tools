## Calcula primero el monto del descuento

Para saber cuánto dinero te descuentan, multiplica el precio original por el porcentaje de descuento dividido entre 100.

```txt
precio original x descuento / 100
```

Si quieres repasar la lógica general de esta operación, consulta [cómo calcular porcentajes](/blog/matematicas/como-calcular-porcentajes).

Si un producto cuesta $1,200 y tiene 25% de descuento:

```txt
1200 x 25 / 100 = 300
```

El descuento es de $300.

## Después calcula el precio final

Resta el descuento al precio original.

```txt
1200 - 300 = 900
```

El precio final es de $900.

## Cuidado con descuentos encadenados

Dos descuentos consecutivos no se suman de forma directa. Si una tienda aplica primero 20% y después 10%, el segundo descuento se calcula sobre el precio ya rebajado.

En un producto de $1,000:

```txt
1000 - 20% = 800
800 - 10% = 720
```

El descuento total no es 30%, sino 28%.

## Compara siempre el precio final

El porcentaje ayuda a entender la promoción, pero el dato más útil suele ser el precio final. Para compras grandes, calcula también costos de envío, intereses o impuestos antes de decidir.
