Si mides 1.65 m, el rango saludable de referencia para adultos es aproximadamente **50.4 kg a 67.8 kg**, usando IMC de 18.5 a 24.9.

Este intervalo ayuda a ubicar el peso en relación con la estatura, pero no define por sí solo tu estado de salud.

## Rango saludable para 1.65 m

| Estatura | Peso mínimo por IMC 18.5 | Peso máximo por IMC 24.9 |
| -------- | ------------------------ | ------------------------ |
| 1.65 m   | 50.4 kg                  | 67.8 kg                  |

La tabla adulta de IMC se usa como referencia para personas adultas. En menores de edad se usan percentiles, no estos rangos.

## Cómo se obtiene el rango

Primero se parte de la fórmula:

```txt
IMC = peso_kg / altura_m^2
```

Luego se despeja el peso:

```txt
peso = IMC x altura_m^2
```

Con 1.65 m:

```txt
1.65^2 = 2.7225
18.5 x 2.7225 = 50.4 kg
24.9 x 2.7225 = 67.8 kg
```

## Ejemplos con diferentes pesos

| Peso  | IMC aproximado | Lectura adulta        |
| ----- | -------------- | --------------------- |
| 50 kg | 18.4           | Cerca del límite bajo |
| 60 kg | 22.0           | Rango saludable       |
| 68 kg | 25.0           | Inicio de sobrepeso   |

El redondeo puede mover el resultado por una décima, especialmente cerca de 18.5 o 25.

## Peso saludable vs peso ideal

Si buscas un peso ideal para 1.65 m, evita quedarte con una sola cifra. Un rango es más realista porque permite diferencias entre personas.

Por ejemplo, 55 kg y 65 kg pueden estar dentro del rango adulto de referencia para 1.65 m, aunque sean cuerpos distintos. Lee más en [peso ideal vs peso saludable](/blog/peso-ideal-vs-peso-saludable).

## Preguntas frecuentes

### Si mido 1.65 m, 60 kg está bien?

60 kg da un IMC aproximado de 22.0, dentro del rango saludable adulto.

### Cuál es el rango para 1.65 m?

El rango adulto de referencia es 50.4 kg a 67.8 kg.

### Sirve para embarazo?

No como interpretación directa. Durante el embarazo se evalúa el aumento de peso con criterios específicos.
