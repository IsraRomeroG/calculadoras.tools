El IMC y el índice cintura-altura son dos formas simples de observar aspectos distintos del cuerpo.

El IMC compara peso y altura. El índice cintura-altura compara la medida de cintura con la altura, por lo que aporta información relacionada con grasa abdominal o adiposidad central.

## Qué es el IMC

El IMC se calcula con esta fórmula:

```txt
IMC = peso / altura^2
```

Sirve como referencia general para ubicar un resultado en categorías adultas como bajo peso, rango saludable, sobrepeso u obesidad.

Puedes calcularlo con la [calculadora de IMC](/salud/calculadora-de-imc/).

## Qué es el índice cintura-altura

El índice cintura-altura compara la circunferencia de cintura con la altura. Es una medida simple que intenta aportar contexto sobre grasa abdominal.

No reemplaza una evaluación médica, pero puede complementar el IMC porque mide algo distinto.

## Fórmula del índice cintura-altura

La fórmula es:

```txt
ICA = cintura_cm / altura_cm
```

Ejemplo:

```txt
cintura = 85 cm
altura = 170 cm
ICA = 85 / 170
ICA = 0.50
```

Un resultado de 0.50 suele usarse como umbral orientativo para prestar atención a la cintura en relación con la altura, aunque la interpretación puede variar según edad, sexo y contexto clínico.

## Diferencias y usos

| Aspecto | IMC | Índice cintura-altura |
|---------|-----|-----------------------|
| Usa peso | Sí | No |
| Usa altura | Sí | Sí |
| Usa cintura | No | Sí |
| Mide grasa directamente | No | No |
| Aporta contexto abdominal | No | Sí |
| Es diagnóstico por sí solo | No | No |

El IMC puede salir alto por masa muscular. El índice cintura-altura puede aportar información adicional sobre distribución de grasa, pero tampoco explica todo.

## Cuando conviene mirar ambos

Puede ser útil mirar ambos cuando:

- El IMC está cerca de una frontera.
- Hay duda por masa muscular.
- Se quiere considerar grasa abdominal.
- Se busca una lectura más completa antes de hablar con un profesional.

## Preguntas frecuentes

### Qué mide mejor la grasa abdominal?

El índice cintura-altura aporta más contexto sobre cintura que el IMC, pero no mide grasa directamente.

### El índice cintura-altura reemplaza al IMC?

No necesariamente. Son indicadores distintos y pueden complementarse.

### Cómo se mide la cintura?

Debe medirse con una cinta flexible, siguiendo una técnica consistente. Si se usa para decisiones de salud, conviene hacerlo con orientación profesional.
