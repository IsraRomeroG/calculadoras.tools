La pregunta "cuánto debería pesar según mi estatura" no tiene una respuesta única. Lo más responsable es hablar de un rango saludable de referencia, no de un peso exacto.

Una forma común de estimar ese rango en adultos es usar el IMC de 18.5 a 24.9.

## No hay un peso único para cada estatura

Dos personas pueden medir lo mismo y tener pesos distintos dentro de un rango saludable. La diferencia puede deberse a masa muscular, estructura corporal, edad, sexo, nivel de actividad y otros factores.

Por eso, en vez de preguntar por un peso exacto, suele ser más útil preguntar:

```txt
Cuál es el rango saludable de referencia para mi estatura?
```

## Rango saludable según IMC

El rango se calcula así:

```txt
peso mínimo = 18.5 x altura_m^2
peso máximo = 24.9 x altura_m^2
```

Por ejemplo, para una persona adulta que mide 1.70 m:

```txt
peso mínimo = 18.5 x 1.70^2 = 53.5 kg
peso máximo = 24.9 x 1.70^2 = 72.0 kg
```

Ese rango no significa que cualquier persona de 1.70 m deba apuntar a un número concreto. Es una referencia basada en IMC.

## Ejemplos por estatura

| Estatura | Rango saludable de referencia |
| -------- | ----------------------------- |
| 1.60 m   | 47.4 a 63.7 kg                |
| 1.70 m   | 53.5 a 72.0 kg                |
| 1.80 m   | 59.9 a 80.7 kg                |

## Factores que el IMC no considera

El IMC solo usa peso y altura. No considera:

- Masa muscular.
- Porcentaje de grasa corporal.
- Distribución de grasa.
- Embarazo.
- Edad avanzada.
- Diferencias individuales de composición corporal.

Por eso, si haces mucho ejercicio de fuerza, si estás embarazada, si eres adolescente o si tienes una condición médica, el rango de IMC puede no contar toda la historia.

## Cómo calcular tu rango exacto

1. Convierte tu altura a metros.
2. Eleva la altura al cuadrado.
3. Multiplica por 18.5 para obtener el límite inferior.
4. Multiplica por 24.9 para obtener el límite superior.

Ejemplo para 1.65 m:

```txt
1.65^2 = 2.7225
18.5 x 2.7225 = 50.4 kg
24.9 x 2.7225 = 67.8 kg
```

## Preguntas frecuentes

### Por qué se habla de rango y no de peso exacto?

Porque el peso saludable puede variar entre personas con la misma estatura.

### El peso cambia por sexo?

La fórmula del IMC adulto es la misma, pero la composición corporal puede variar y afectar la interpretación.

### El peso saludable cambia con la edad?

La lectura puede requerir más cuidado en adultos mayores y no aplica igual en niños y adolescentes.
