El peso saludable según estatura se puede estimar usando el rango de IMC adulto de 18.5 a 24.9. El resultado no es un peso único, sino un rango de referencia.

Hablar de rango es importante porque dos personas con la misma estatura pueden tener composiciones corporales distintas.

## Cómo se calcula el peso saludable según estatura

La fórmula del IMC es:

```txt
IMC = peso / altura^2
```

Si despejamos el peso:

```txt
peso = IMC x altura^2
```

Para estimar el rango saludable adulto se usan dos límites:

```txt
peso mínimo = 18.5 x altura_m^2
peso máximo = 24.9 x altura_m^2
```

## Ejemplos: 1.60 m, 1.70 m y 1.80 m

Para 1.60 m:

```txt
18.5 x 1.60^2 = 47.4 kg
24.9 x 1.60^2 = 63.7 kg
```

Para 1.70 m:

```txt
18.5 x 1.70^2 = 53.5 kg
24.9 x 1.70^2 = 72.0 kg
```

Para 1.80 m:

```txt
18.5 x 1.80^2 = 59.9 kg
24.9 x 1.80^2 = 80.7 kg
```

## Peso saludable no es lo mismo que peso ideal

El peso ideal suele presentarse como un número exacto. Eso puede ser útil para algunos cálculos, pero en salud suele ser más prudente hablar de rangos.

Un rango permite reconocer que la composición corporal, edad, sexo, masa muscular y otros factores influyen en la interpretación.

## Limitaciones del cálculo

Este cálculo se basa únicamente en altura e IMC. No considera:

- Masa muscular.
- Porcentaje de grasa corporal.
- Medida de cintura.
- Edad.
- Embarazo.
- Historial médico.

Tampoco aplica igual en niños y adolescentes, donde se usan percentiles por edad y sexo.

## Preguntas frecuentes

### Cómo se calcula el rango por estatura?

Se multiplica la altura en metros al cuadrado por 18.5 y por 24.9.

### Es lo mismo peso ideal que peso saludable?

No. El peso saludable es mejor entenderlo como rango de referencia, no como número único.

### El rango aplica para deportistas?

Puede ser menos preciso en personas con mucha masa muscular. En ese caso conviene revisar otros indicadores.
