Si mides 1.50 m, el rango de peso saludable de referencia para adultos es aproximadamente **41.6 kg a 56.0 kg**, calculado con IMC de 18.5 a 24.9.

Este rango no es un diagnóstico ni una meta obligatoria. Es una referencia inicial para relacionar peso y estatura.

## Rango saludable para 1.50 m

Para una estatura de 1.50 m, el rango queda así:

| Estatura | Peso mínimo por IMC 18.5 | Peso máximo por IMC 24.9 |
| -------- | ------------------------ | ------------------------ |
| 1.50 m   | 41.6 kg                  | 56.0 kg                  |

Si buscas "peso ideal 1.50 mujer" o "peso ideal 1.50", conviene tomar este dato como rango y no como un número único. La composición corporal, la edad, la masa muscular y el contexto de salud pueden cambiar la interpretación.

## Cómo se calcula

La fórmula del IMC es:

```txt
IMC = peso_kg / altura_m^2
```

Para obtener el rango por estatura, se despeja el peso:

```txt
peso = IMC x altura_m^2
```

Con 1.50 m:

```txt
peso mínimo = 18.5 x 1.50^2 = 41.6 kg
peso máximo = 24.9 x 1.50^2 = 56.0 kg
```

## Por qué no hay un peso único

Dos personas de 1.50 m pueden pesar lo mismo y tener distinta composición corporal. Una puede tener más masa muscular, otra más grasa corporal, y otra puede estar en una etapa de vida donde el IMC se interpreta diferente.

Por eso, hablar de rango de peso saludable suele ser más útil que hablar de un "peso ideal" exacto.

Puedes ver el enfoque completo en [peso ideal vs peso saludable](/blog/salud/peso-ideal-vs-peso-saludable).

## Ejemplos de IMC con diferentes pesos

Para 1.50 m:

| Peso  | IMC aproximado | Lectura adulta  |
| ----- | -------------- | --------------- |
| 40 kg | 17.8           | Bajo peso       |
| 48 kg | 21.3           | Rango saludable |

Estos ejemplos usan categorías adultas. No aplican igual para niños, adolescentes o embarazo.

## Preguntas frecuentes

### Si mido 1.50 m, debo pesar exactamente 50 kg?

No. 50 kg cae dentro del rango saludable de referencia, pero no es una obligación ni una meta universal.

### El rango aplica para hombres y mujeres?

En adultos, el cálculo de IMC usa la misma fórmula. La interpretación individual puede necesitar otros datos.

### Este rango sirve para adolescentes?

No. En niños y adolescentes se usan percentiles por edad y sexo, no la tabla adulta.
