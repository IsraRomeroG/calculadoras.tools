## Tipos de IVA en España

En España, el IVA tiene un tipo general y tipos reducidos. La Agencia Tributaria indica que el tipo general es 21%, y que existen tipos reducidos de 10%, 4% y 0% para determinadas operaciones.

En una compra común gravada al tipo general, si el precio sin IVA es de 1,000 €:

```txt
iva = 1000 x 21 / 100 = 210
total = 1000 + 210 = 1210
```

El total con IVA sería 1,210 €.

## Cuándo se usa el 21%

El 21% es el tipo general. Se usa como referencia para bienes y servicios que no tienen asignado un tipo reducido, superreducido, cero o alguna exención.

Para calcularlo rápidamente, multiplica el precio sin IVA por `1.21`.

```txt
precio con iva = precio sin iva x 1.21
```

## Qué son el 10%, el 4% y el 0%

El 10% y el 4% son tipos reducidos que aplican a bienes o servicios específicos. El 0% también aparece para determinadas operaciones. No deben usarse por intuición: dependen de la clasificación fiscal de la operación.

Ejemplo con 10%:

```txt
base = 500
iva = 500 x 0.10 = 50
total = 550
```

Ejemplo con 4%:

```txt
base = 500
iva = 500 x 0.04 = 20
total = 520
```

## Cómo desglosar IVA incluido en España

Si un precio ya incluye IVA de 21%, divide entre `1.21`.

```txt
precio sin iva = precio con iva / 1.21
iva = precio con iva - precio sin iva
```

Ejemplo con 1,210 € IVA incluido:

```txt
precio sin iva = 1210 / 1.21 = 1000
iva = 1210 - 1000 = 210
```

Si quieres ver las fórmulas generales paso a paso, revisa [cómo sumar IVA a un precio](/blog/legal-impuestos/como-sumar-iva-a-un-precio) y [cómo desglosar IVA incluido](/blog/legal-impuestos/como-desglosar-iva).
