## Antes de usar esta tabla

Las tasas de IVA cambian con el tiempo y pueden depender del producto, servicio, región, régimen o tipo de contribuyente. Usa esta tabla como referencia inicial, no como sustituto de una fuente oficial.

Para cálculos rápidos, puedes usar la [calculadora de IVA](/legal-impuestos/calculadora-de-iva) y editar manualmente la tasa.

## Cómo usar la tasa correcta

Si tienes un precio sin impuesto, multiplica por la tasa:

```txt
iva = precio base x tasa / 100
total = precio base + iva
```

Si tienes un precio con impuesto incluido, divide entre `1 + tasa / 100`:

```txt
precio base = precio final / (1 + tasa / 100)
iva = precio final - precio base
```

## Ejemplo de comparación

Un precio base de $1,000 cambia así según la tasa:

| Tasa | Impuesto | Total |
|---:|---:|---:|
| 12% | $120 | $1,120 |
| 16% | $160 | $1,160 |
| 18% | $180 | $1,180 |
| 19% | $190 | $1,190 |
| 21% | $210 | $1,210 |
| 22% | $220 | $1,220 |

## Por qué hay tasas reducidas

Muchos países usan tasas reducidas para ciertos bienes o servicios. También pueden existir operaciones exentas, excluidas, inafectas o gravadas a tasa 0%. Aunque matemáticamente parezcan similares, fiscalmente no siempre significan lo mismo.

Por eso, si vas a emitir una factura, declarar impuestos o fijar precios oficiales, revisa la fuente oficial.

- Perú: [SUNAT, Impuesto General a las Ventas](https://emprender.sunat.gob.pe/principales-impuestos/impuesto-general-las-ventas-igv/impuesto-general-las-ventas).
- Chile: [SII, VAT for foreign investors](https://www.sii.cl/destacados/foreign_investor/vat.html).
- Costa Rica: [Ministerio de Hacienda, tarifas del IVA](https://www.hacienda.go.cr/docs/TarifasdelIVA.pdf).
- Uruguay: [DGI, tasa básica del 22%](https://www.gub.uy/direccion-general-impositiva/comunicacion/publicaciones/son-bienes-servicios-gravados-tasa-basica-del-22).
- Ecuador: [SRI, Impuesto al Valor Agregado](https://www.sri.gob.ec/web/intersri/impuesto-al-valor-agregado-iva).

Revisa la fecha de actualización de cada fuente antes de usar una tasa para fines fiscales.
