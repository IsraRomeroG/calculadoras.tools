## Qué es el IGV

En Perú, el impuesto equivalente al IVA se conoce como IGV: Impuesto General a las Ventas. SUNAT explica que se cobra en la compra final de bienes o servicios gravados.

La tasa aplicable total es 18% sobre la operación gravada. Para 2026, SUNAT muestra esa tasa como una composición de 15.5% de IGV y 2.5% de Impuesto de Promoción Municipal (IPM), manteniendo el 18% como tasa aplicable total para el cálculo.

En la práctica, ese 18% suele usarse para sumar el impuesto a un precio base o desglosarlo desde un total.

## Cómo calcular IGV sobre un precio sin impuesto

Si tienes un precio sin IGV, aplica esta fórmula:

```txt
igv = precio sin igv x 18 / 100
total = precio sin igv + igv
```

Ejemplo con S/ 1,000:

```txt
igv = 1000 x 0.18 = 180
total = 1000 + 180 = 1180
```

El total con IGV sería S/ 1,180.

## Cómo desglosar IGV incluido

Si el precio ya incluye IGV de 18%, divide el total entre `1.18`.

```txt
precio sin igv = precio con igv / 1.18
igv = precio con igv - precio sin igv
```

Ejemplo con S/ 1,180:

```txt
precio sin igv = 1180 / 1.18 = 1000
igv = 1180 - 1000 = 180
```

La operación es la misma que se usa para otros impuestos tipo IVA. Puedes verla con más detalle en las guías de [cómo sumar IVA a un precio](/blog/legal-impuestos/como-sumar-iva-a-un-precio) y [cómo desglosar IVA incluido](/blog/legal-impuestos/como-desglosar-iva).

## IGV, exoneraciones e inafectaciones

No todas las operaciones se tratan igual. SUNAT señala que el IGV aplica a actividades gravadas, con excepciones como exportaciones, exoneraciones, inafectaciones u otros casos previstos por norma.

Para cálculos cotidianos puedes usar 18%, pero para documentos tributarios conviene verificar si tu operación está realmente gravada.
