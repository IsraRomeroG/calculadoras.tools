## Cuándo necesitas sumar IVA

Necesitas sumar IVA cuando partes de un precio base, también llamado precio neto o precio sin impuesto, y quieres saber cuánto debe pagar el cliente en total.

Esto pasa mucho en cotizaciones, presupuestos, servicios profesionales, ventas B2B y comparaciones de precios donde el proveedor muestra importes "más IVA".

## Fórmula para sumar IVA

La fórmula tiene dos pasos:

```txt
iva = precio sin iva x tasa / 100
total = precio sin iva + iva
```

Si prefieres hacerlo en una sola operación:

```txt
total = precio sin iva x (1 + tasa / 100)
```

## Ejemplo con precio de $500

Si el precio sin IVA es $500 y la tasa es 16%:

```txt
iva = 500 x 16 / 100 = 80
total = 500 + 80 = 580
```

El cliente pagaría $580 en total.

## Ejemplo con una cotización de $3,250

Si quieres cotizar un servicio de $3,250 más IVA al 16%:

```txt
iva = 3250 x 0.16 = 520
total = 3250 + 520 = 3770
```

La cotización final sería de $3,770.

## Atajo mental para tasas comunes

Para una tasa de 16%, multiplica por `1.16`.

```txt
500 x 1.16 = 580
```

Para una tasa de 21%, multiplica por `1.21`. Para una tasa de 19%, multiplica por `1.19`.

Este atajo funciona bien para calcular el total, pero si necesitas mostrar el desglose, conviene calcular también el monto exacto del impuesto.

## Qué mostrar en una cotización

Un desglose claro suele incluir:

- Precio sin IVA.
- Tasa aplicada.
- IVA calculado.
- Total con IVA.

Ejemplo:

```txt
Precio sin IVA: $500.00
IVA (16%): $80.00
Total con IVA: $580.00
```

Ese formato evita confusiones y ayuda al cliente a entender qué parte corresponde al impuesto.
