## Error 1: quitar el IVA restando el porcentaje directo

Este es el error más común. Si un precio de $116 incluye IVA de 16%, muchas personas hacen:

```txt
116 - 16% = 97.44
```

Pero el precio sin IVA correcto es $100. Para desglosar IVA incluido debes dividir:

```txt
116 / 1.16 = 100
116 - 100 = 16
```

El IVA se agregó sobre la base, no sobre el total.

## Error 2: confundir precio sin IVA con precio con IVA

Una cotización de `$1,000 más IVA` no es igual a una cotización de `$1,000 IVA incluido`.

Con tasa de 16%:

```txt
1000 más IVA = 1160 total
1000 IVA incluido = 862.07 base + 137.93 IVA
```

Antes de comparar precios, confirma si todos están expresados con la misma condición.

## Error 3: usar la tasa equivocada

Cada país tiene sus propias tasas. Además, puede haber tasas reducidas, tasa 0%, exenciones o tratamientos especiales.

Ejemplos comunes:

- México suele usar 16% como tasa general.
- España usa 21% como tipo general.
- Colombia usa 19% como tarifa general.
- Perú usa IGV de 18%.

Pero esos datos no sustituyen la revisión del caso concreto.

Puedes revisar las guías específicas de [IVA en México](/blog/legal-impuestos/iva-mexico), [IVA en España](/blog/legal-impuestos/iva-espana), [IVA en Colombia](/blog/legal-impuestos/iva-colombia) e [IGV en Perú](/blog/legal-impuestos/igv-peru), o comparar más países en la [tabla de tasas de IVA](/blog/legal-impuestos/tasas-de-iva-por-pais).

## Error 4: tratar tasa 0%, exento y excluido como lo mismo

Matemáticamente, una tasa de 0% produce impuesto cero. Pero fiscalmente no siempre equivale a estar exento, excluido o no sujeto.

Si solo haces una estimación de precio, el resultado puede ser el mismo. Si estás facturando o declarando, la diferencia puede afectar obligaciones, acreditamientos o reportes.

## Error 5: redondear demasiado pronto

Si redondeas cada paso antes de terminar, pueden aparecer diferencias de centavos.

Lo recomendable es:

1. Calcular con la mayor precisión disponible.
2. Redondear moneda al final.
3. Mostrar base, impuesto y total de forma consistente.

Esto es especialmente importante en facturas con varios conceptos.

## Error 6: no separar impuestos múltiples

Si además del IVA hay otro impuesto, no asumas que todos se aplican igual. Algunos impuestos son aditivos sobre la misma base; otros pueden ser secuenciales o depender de reglas especiales.

Para una cotización simple, separa cada línea:

```txt
Precio base
IVA
Otro impuesto o cargo
Total
```

## Cómo evitar estos errores

Usa una fórmula clara:

```txt
sumar iva: precio base x (1 + tasa / 100)
desglosar iva: precio final / (1 + tasa / 100)
```

También puedes usar la [calculadora de IVA](/legal-impuestos/calculadora-de-iva), que muestra el desglose completo y permite cambiar la tasa manualmente.

## Cuándo consultar a un especialista

Si el cálculo será usado para facturación, declaraciones, contratos o precios oficiales, confirma la tasa y el tratamiento fiscal con la fuente oficial o con un contador. La calculadora ayuda con la parte matemática, pero no determina por sí sola la clasificación fiscal de una operación.
