## Decimal to percentage

Multiply by 100 and add the percent sign:

```txt
0.35 x 100 = 35%
1.2 x 100 = 120%
```

## Percentage to decimal

Divide by 100:

```txt
7.5% / 100 = 0.075
```

## Fraction to percentage

Divide the numerator by the denominator, then multiply by 100:

```txt
3 / 4 = 0.75 = 75%
```

| Fraction | Decimal | Percentage |
| ---: | ---: | ---: |
| 1/2 | 0.5 | 50% |
| 1/4 | 0.25 | 25% |
| 3/4 | 0.75 | 75% |
| 1/5 | 0.2 | 20% |
| 1/3 | 0.333... | 33.33...% |

Do not move the decimal point without checking direction: percent to decimal divides by 100; decimal to percent multiplies by 100. Retain enough precision for repeating fractions and round only at the end.
