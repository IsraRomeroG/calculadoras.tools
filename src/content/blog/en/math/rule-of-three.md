The rule of three finds an unknown value in a direct proportion. If `a` corresponds to `b`, and `c` corresponds to `x`:

```txt
a / b = c / x
x = b x c / a
```

If 3 notebooks cost `$12`, then 5 notebooks cost:

```txt
3 / 12 = 5 / x
x = 12 x 5 / 3 = 20
```

The result is `$20`.

Arrange like units in the same positions before cross-multiplying. Then check whether the relationship is direct: when one quantity increases, should the other increase too? Fuel used over a fixed efficiency is direct; workers and time for a fixed job may be inverse and require a different setup.

Finally, inspect the units and estimate the scale. Five notebooks should cost more than three, so a result below `$12` would signal an error.
